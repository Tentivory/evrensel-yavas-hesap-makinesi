# Evrensel Yavaş Hesap Makinesi

Bu proje, insanlığın en büyük sorununu çözmek için yaratıldı: **Hesaplamaların çok hızlı yapılması.**

Modern dünyada her şey o kadar hızlı ki, sonuçlar doğru mu diye düşünmeye zaman kalmıyor. Bu hesap makinesi ise **düşünür**. Her işlemi milim milim, saniye saniye hesaplar. Çünkü gerçek doğruluk, acele etmeyenlerde bulunur.

## Nasıl Çalışır?

1. İki sayı girersiniz.
2. Program derin bir nefes alır.
3. Her birimi tek tek sayar, çünkü "1+1=2" demek kolay ama **hissetmek** başka.
4. Sonucu, evrenin onayını aldıktan sonra verir.

**Uyarı:** Büyük sayılarla kullanmayın. Yoksa hayatınızın anlamını bulursunuz.

## Kurulum

Python 3 yeter. Başka bir şeye ihtiyacınız yok. Çünkü bu proje, minimalizmin zirvesidir.

```bash
python hesapla.py
```

## Özellikler

- %100 doğru sonuçlar (eğer sabrederseniz)
- Sıfır bağımlılık
- Sonsuz beklemeye açık mimari
- Felsefi derinlik (opsiyonel)

## Lisans

Bu proje, "Düşündüğün için teşekkürler" lisansı altındadır. Kullanırsanız, bir sonraki hesaplamada biraz daha yavaş olun.
